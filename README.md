# 🎮 QuizBattleArena

A real-time multiplayer quiz game built using **JavaScript, Vite, and Firebase**.

QuizBattleArena allows players to participate in quiz challenges and compete through a multiplayer gaming experience.

## 🚀 Technologies Used

- JavaScript
- HTML
- CSS
- Vite
- Firebase Realtime Database

## ✨ Project Overview

QuizBattleArena is designed to provide an interactive quiz experience with real-time multiplayer functionality.

## ⚙️ Installation and Setup

1. Clone the repository:

   git clone https://github.com/kalpana-57/QuizBattleArena.git

2. Open the project folder:

   cd QuizBattleArena

3. Install dependencies:

   npm install

4. Configure Firebase using your own Firebase project settings.

5. Start the development server:

   npm run dev

## 🎯 Objective

To build an interactive multiplayer quiz application using modern web technologies and Firebase.
